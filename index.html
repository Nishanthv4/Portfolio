PROJECT_01 // ARCHITECTURE

StudyMate — Deep Dive

Student productivity platform with intelligent timetable and task rescheduling

Problem Statement

Undergraduate engineering schedules can become chaotic with varying lab periods, sudden lecture changes, and tight submission windows. Traditional generic planners fail when a student misses a dedicated slot, leading to abandonment.

Technical Architecture

  • Local-First Philosophy: Zero external latency. Tasks and subjects are persisted in the browser's localStorage, allowing full offline operability.
  • Rescheduling Engine: An algorithmic routine that identifies missed tasks and inserts them into the next available gap in the weekly calendar.
  • Exam Countdown Component: Real-time millisecond countdown calculation updating the DOM efficiently.
  • Data Portability: Native JSON export and import options so students never lose their study configurations.

Repository & Status

Developed as a core academic project. Source code available on GitHub profile: github.com/Nishanthv4.

PROJECT_02 // ARCHITECTURE

AI News Detector — Deep Dive

AI-assisted content credibility evaluation and context analysis

Problem Statement

Online headlines are frequently amplified for rage-clicks or commercial ad impressions. Rather than attempting to serve as an infallible arbiter of truth, this tool equips users with objective contextual signals to evaluate claims themselves.

System Design & Ethical Constraints

  • Ethical Boundary: Explicitly designed NOT to output binary "True or False" decrees. Credibility is nuanced, multi-faceted, and relies on transparent source attribution.
  • Heuristic Signals: Scans for sensationalism markers, emotional sentiment skew, anonymous assertions, and missing publication citations.
  • Gemini API Integration Concept: Leverages large language model context extraction to summarize counter-evidence and provide non-partisan context.
  • User Interface: Built with semantic HTML and clean CSS modules for lightning-fast parsing on desktop and mobile browsers.

Repository & Status

Source code and research notes available on GitHub: github.com/Nishanthv4.
