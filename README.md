# Nishanth V — Terminal-inspired portfolio
A responsive portfolio made with plain HTML, CSS, and JavaScript. No build tools required.

## Run locally
Extract the ZIP and open `index.html` in a browser. For live reload, open the folder in VS Code and use the Live Server extension.

## Customize before publishing
Edit `index.html`:
- Replace the sample GitHub and LinkedIn URLs with your profile URLs.
- Replace `your.email@example.com` with your email.
- Add your resume PDF at `assets/resume.pdf` (create the `assets` folder).
- Add real GitHub repository and live demo URLs to the project cards.
- Update skills, project descriptions, and education details as they change.

The skill labels are deliberately marked as foundations/learning/exploring. Keep them accurate to your experience.

## Deploy to Vercel
1. Push the contents of this folder to a GitHub repository.
2. Import the repository in Vercel.
3. Select Framework Preset: Other.
4. Leave build command empty; use `.` as the output directory if required.
5. Deploy. This is a static site and needs no server or environment variables.
